## Regression boundaries

- Profile deletion checks use real temporary files: fallback loading, cancellation, changed path hints, missing/invalid/locked files, changed catalog/file during confirmation, and failed rereads. A failed operation must preserve both file and active profiles.
- Diagnostic checks invoke actual form error/status handlers and worker callbacks. Password/Pwd-shaped values are masked, including quoted values. This does not promise discovery of every possible secret embedded in arbitrary SQL or prose.
- The database integration command uses only a newly created dedicated LocalDB instance and unique synthetic databases. It does not accept a production connection string or read saved user profiles. Oracle is not implied by successful SQL Server results.
- Framework compatibility outputs are never published. The released target and minimum framework remain unchanged until a reviewed migration passes its adoption checklist.

No production database operations, credential rotation, Git-history rewrite, licence selection or automatic PR merge are performed by this audit.
