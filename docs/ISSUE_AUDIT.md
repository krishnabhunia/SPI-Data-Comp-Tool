## Verification boundaries

- Profile checks use temporary files and actual editor/import/save/delete entry points. Cancellation, stale ownership, changes during dialogs, changed/missing/locked files and unavailable settings must preserve existing data. Detected external modifications are rejected; this is not a distributed file-locking protocol.
- SQL integration uses a newly created dedicated LocalDB instance, unique synthetic databases and generated read-only logins. It accepts no production connection string and does not touch the user's normal `MSSQLLocalDB` instance. Oracle success is not inferred from SQL results.
- Matching measurements record actual timing and memory for deterministic fixtures and assert their results. They are not universal capacity limits or complete database-to-Excel throughput measurements.
- Portable updates reject unmet runtime prerequisites before changing payload or preferences. The installed-update path invokes Inno Setup's prerequisite check before application replacement and attempts preference rollback on failure; it does not share the portable no-write guarantee.
- Older portable updater binaries cannot acquire the new framework preflight retroactively. Install .NET Framework 4.8 first, or use the new installer. Dependency notices are separate release assets so they do not break older strict portable-archive allowlists.
- Historical credential rotation, Git-history rewrites, license choices, external publication rights and automatic master merges are not performed by this PR.
