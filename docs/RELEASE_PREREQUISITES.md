## Runtime requirement

**Microsoft .NET Framework 4.8 or later is required.**

Before updating from an older SPI build, install the runtime from [Microsoft](https://dotnet.microsoft.com/download/dotnet-framework/net48), or use the 64-bit installer, which checks the prerequisite before changing application files. Earlier portable updaters cannot check this new requirement; install the runtime first before updating a portable copy.

Keep a copy of your existing portable folder or installer and your profile/rules files until you have checked the new version. The runtime requirement applies to both portable and installed builds. Installing a framework does not extend the support lifecycle of Windows.
